# Budget du foyer

Plateforme de gestion de budget mensuel pour un couple en Algérie (montants en dinars, DA) :
courses avec prix saisis, inventaire frigo, cuisine qui retire les ingrédients du stock,
factures, dettes avec échéances, épargne, escapades à deux, conseils et historique.

C'est une seule page web (`index.html`), sans serveur ni installation.

## Mettre la plateforme en ligne avec GitHub Pages

1. Créez un dépôt GitHub (par exemple `budget-foyer`).
2. Déposez-y `index.html`, `.nojekyll` et `README.md`.
3. Dans le dépôt : **Settings, Pages, Build and deployment, Deploy from a branch**, choisissez la branche `main` et le dossier `/ (root)`.
4. Après une ou deux minutes, la page est disponible à l'adresse `https://VOTRE-NOM.github.io/budget-foyer/`.
5. Sur le téléphone, ouvrez l'adresse puis « Ajouter à l'écran d'accueil » pour l'utiliser comme une application.

## Vos données

- Sur GitHub Pages, les données sont enregistrées **dans le navigateur de chaque appareil**. Le téléphone, le PC et la tablette ne se synchronisent pas entre eux.
- Pour les transférer, utilisez *Accueil, Réglages, Télécharger une sauvegarde* sur un appareil, puis *Importer une sauvegarde* sur l'autre.
- La version publiée dans Claude se synchronise automatiquement entre les appareils des personnes à qui elle est partagée.
- Ne publiez pas de données personnelles dans un dépôt public : le fichier `index.html` ne contient que la plateforme, pas vos chiffres.

## Modifier la plateforme

Tout le code est dans `index.html` (HTML, CSS et JavaScript). Aucun outil de compilation n'est nécessaire.
